# latent

## Overview

Correlation of normal variables assumed to underlie ordinal observations.

## Components

| Component | Description |
|-----------|-------------|
| [polychoric.py](./polychoric.py) | `Polychoric`, for two ordinal variables. |
| [tetrachoric.py](./tetrachoric.py) | `Tetrachoric`, for two binary variables. |
| [polyserial.py](./polyserial.py) | `Polyserial`, for an ordinal and a numeric variable. |
| [biserial.py](./biserial.py) | `Biserial`, for a binary and a numeric variable. |
| [bivariate_normal.py](./bivariate_normal.py) | `BivariateNormal`, the distribution function behind the likelihood. |
