# options

## Overview

Enumerations that metrics take as options, each translating to the name its backing library expects where it has one.

## Components

| Component | Description |
|-----------|-------------|
| [alternative.py](./alternative.py) | `Alternative`, the hypothesis of a significance test. |
| [entropy_average.py](./entropy_average.py) | `EntropyAverage`, the normalizer of mutual information. |
| [intraclass_form.py](./intraclass_form.py) | `IntraclassForm`, the study design of an intraclass correlation. |
| [kappa_weighting.py](./kappa_weighting.py) | `KappaWeighting`, the penalty of Cohen's kappa. |
| [kendall_variant.py](./kendall_variant.py) | `KendallVariant`, tau-b or tau-c. |
